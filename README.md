# 🌍 Travelgram — Perfil de Viagens

Projeto desenvolvido por mim acompanhando as aulas da Rocketseat, utilizando HTML e CSS para criar uma página de perfil de viagens.

## 💻 Sobre o projeto

O Travelgram é uma interface inspirada em uma rede social de viagens, onde uma viajante apresenta seu perfil e compartilha registros dos lugares que visitou.

A página reúne:

- Menu de navegação com logo, busca e foto de perfil.
- Apresentação da viajante com nome, foto e biografia.
- Informações sobre localização, países visitados e fotos.
- Galeria com 12 imagens de viagens.
- Rodapé com informações da página.

## 🚀 Tecnologias utilizadas

- **HTML5** para estruturar o conteúdo.
- **CSS3** para estilizar e organizar os elementos.
- **Google Fonts** para utilizar a fonte Poppins.

## 📚 Conceitos praticados

Durante o desenvolvimento, pratiquei:

- Estruturação de páginas com HTML semântico.
- Organização de elementos com Flexbox.
- Uso de variáveis CSS para definir cores e tipografia.
- Ajustes de espaçamento, alinhamento e dimensões.
- Estilização de imagens com `object-fit` e `border-radius`.
- Separação do CSS em arquivos por área da página.

## ▶️ Como visualizar

1. Clique em **Code → Download ZIP** neste repositório.
2. Extraia os arquivos.
3. Abra o arquivo `index.html` no navegador.

Também é possível abrir a pasta no VS Code e visualizar a página com a extensão **Live Server**.
